# Primex Backend

This directory contains the Node.js/Express API server for the Primex platform. It handles user authentication, data persistence, smart contract template management, and Solidity compilation.

## Technology Stack

*   **Node.js:** JavaScript runtime environment.
*   **Express.js:** Web application framework for Node.js.
*   **TypeScript:** Superset of JavaScript that adds static typing.
*   **MongoDB:** NoSQL database used for data persistence.
*   **Mongoose:** ODM (Object Data Modeling) library for MongoDB and Node.js.
*   **JWT (JSON Web Tokens):** For user authentication.
*   **bcryptjs:** Library for hashing passwords.
*   **solc-js:** JavaScript bindings for the Solidity compiler.
*   **Ethers.js:** (Potentially used for blockchain interactions or validations, if any, on the backend).

## Setup and Configuration

1.  **Navigate to the backend directory:**
    ```bash
    cd backend
    ```

2.  **Install Dependencies:**
    If not already done from the root setup:
    ```bash
    npm install
    # or
    # yarn install
    ```

3.  **Environment Variables:**
    Create a `.env` file in the `backend` directory by copying the `.env.example` file (if one exists) or by creating it manually.
    It should contain the following variables:

    ```dotenv
    # Server Configuration
    PORT=5000 # Or any port you prefer

    # MongoDB Configuration
    MONGO_URI=your_mongodb_connection_string # e.g., mongodb://localhost:27017/primex_db

    # JWT Configuration
    JWT_SECRET=your_very_strong_jwt_secret # A long, random, and secret string
    JWT_EXPIRES_IN=1d # e.g., 1d, 7d, 1h

    # Add other environment variables as needed
    ```
    Replace `your_mongodb_connection_string` and `your_very_strong_jwt_secret` with your actual values.

## Available Scripts

In the `backend` directory:

*   **`npm run dev`**: Starts the backend server in development mode using `nodemon`. The server will automatically restart when file changes are detected.
*   **`npm run start`**: Starts the backend server from the compiled JavaScript files in the `dist` directory (production mode).
*   **`npm run build`**: Compiles the TypeScript source code from `src` to JavaScript in `dist`.
*   **`npm run seed`**: (If implemented, e.g., `ts-node src/seedTemplates.ts`) Seeds the database with initial data, such as smart contract templates.
*   **`npm test`**: Runs the backend test suite using Jest.

## API Endpoints Overview

The backend provides several API endpoints. Key resource routes include:

*   **`/api/auth`**: User registration and login.
*   **`/api/users`**: User profile management.
*   **`/api/templates`**: Managing smart contract templates (listing, creating - admin).
*   **`/api/deployments`**: Storing records of deployed smart contracts.
*   **`/api/generator`**:
    *   `POST /compile-template`: Compiles a Solidity template with user-provided parameters, returning ABI and bytecode.

(For detailed API documentation, consider integrating Swagger/OpenAPI in the future.)

## Authentication

User authentication is handled via JSON Web Tokens (JWTs).
1.  Users register or log in through the `/api/auth` endpoints.
2.  Upon successful login, a JWT is issued to the client.
3.  The client must include this JWT in the `Authorization` header (as a Bearer token) for requests to protected API routes.
4.  The `authMiddleware.ts` validates the token for protected routes.

## Folder Structure

*   `src/`: Contains the TypeScript source code.
    *   `config/`: Database configuration (`db.ts`).
    *   `controllers/`: Request handlers that implement the logic for API routes.
    *   `middlewares/`: Custom Express middleware (e.g., `authMiddleware.ts`).
    *   `models/`: Mongoose schema definitions for database collections (e.g., `User.ts`, `Template.ts`, `Deployment.ts`, `Project.ts`).
    *   `routes/`: Express route definitions that map API endpoints to controller functions.
    *   `services/`: Business logic services separated from controllers (e.g., `generatorService.ts`).
    *   `server.ts`: Main application file that sets up and starts the Express server.
    *   `seedTemplates.ts`: (Example) Script for seeding initial data.
*   `dist/`: Contains the compiled JavaScript code (generated by `npm run build`).
*   `.env`: Environment variables (should be in `.gitignore`).
*   `package.json`: Project dependencies and scripts.
*   `tsconfig.json`: TypeScript compiler configuration.
